# Signal2000

מערכת CRM למעבדת תיקון מוצרי חשמל בחיפה: טלוויזיות, רדיו, וידאו ועוד.

Flask + SQLite, ממשק בעברית (RTL), בלי שלב build.

## הרצה

```bash
pip install -r requirements.txt
set FLASK_APP=run.py
python -m flask seed-demo      # נתוני דמו (או: python -m flask init-db למסד ריק)
python run.py                  # http://127.0.0.1:5000
```

יצירת מנהל אמיתי במסד ריק:

```bash
python -m flask create-user <username> --role admin
```

משתמשי דמו (סיסמה `demo1234`): `admin`, `tech`, `tech2`, ולקוחות `0521234567` ו-`0547654321`.

## משתמשים

| תפקיד | מה רואים |
|---|---|
| מנהל | קבלת מכשירים, כל התיקונים, לקוחות ומכשירים, היסטוריה, שיוך טכנאים, מחירים, קבלה להדפסה, ניהול צוות וחשבונות לקוחות |
| טכנאי | תור עבודה (הישן ביותר ראשון), לקיחת תיקון, אבחון, הצעת מחיר, עדכון סטטוס והערות (פנימיות או גלויות ללקוח) |
| לקוח | המכשירים שלו והתיקונים שלהם, אישור או דחייה של הצעת מחיר, חנות (בקרוב) |

## מהלך תיקון

התקבל → בבדיקה → ממתין לאישור לקוח → אושר → בתיקון / ממתין לחלקים → מוכן לאיסוף → נמסר

אפשר גם: לא ניתן לתיקון, הלקוח סירב. כל שינוי נשמר בהיסטוריית התיקון.
